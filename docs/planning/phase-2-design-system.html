§00 — Overview

A system for building complete software, not another portfolio template.

Every token below exists to serve Phase 1's UX goals: 10-second comprehension, progressive disclosure, and a cross-linked knowledge graph. Nothing here is decorative — colors, type, spacing, and motion are specified as reusable primitives the component library and wireframes are built from.

§01 — Color

Palette

dark-first · light supported

Graphite and charcoal separate by depth, not hue: charcoal is the canvas, graphite is what sits on it. Emerald carries all interactive/positive meaning; copper is reserved for secondary emphasis and never competes with emerald for the same job. This page itself renders in your system theme — toggle it to see both worked out below.

Charcoal

Success — emerald

Semantic color is intentionally separate from the two brand accents — a red alert should never be mistaken for the copper accent at a glance.

§02 — Typography

Type System

Geist / Inter / Geist Mono

Three families, one job each — never mixed within a role. Geist carries structure (headings, UI chrome, nav). Inter carries reading (paragraphs, case-study prose). Geist Mono carries data (labels, tags, metrics, code) — it's what makes the site read as an engineering artifact instead of a marketing page.
